# Contributing to Touch Redirect

Thanks for your interest in contributing!

## Code of Conduct

By participating, you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting Bugs

Please include:
- macOS version
- Xcode version
- Touch Redirect version
- Steps to reproduce
- Expected vs actual behavior
- Relevant Console.app logs (if available)

## Feature Requests

We welcome ideas. Please describe:
- The problem you’re trying to solve
- How you expect the feature to work
- Why it would benefit users

## Development Setup

See [BUILD.md](BUILD.md) for prerequisites and build steps.

## Pull Requests

1. Fork the repository
2. Create a feature branch
3. Make changes with clear commit messages
4. Ensure the app builds and runs
5. Open a pull request with a clear description

## Code Style

- Follow standard Swift and SwiftUI conventions
- Prefer clarity over cleverness
- Keep functions small and focused
- Use `// MARK:` sections for large files

## Security

Do not include secrets, API keys, or credentials in commits. If you find
exposed credentials, report it privately.
